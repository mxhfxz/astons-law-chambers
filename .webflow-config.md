## Mast Framework Implementation Notes

- Use plain div blocks with Mast classes (never native Webflow blocks)
- Follow the 80/20 rule: 80% Mast defaults, 20% custom code
- All custom classes should follow the naming conventions in `mast-framework.md`
- Use combo classes (cc-) for variants and modifiers

## Deployment Process

1. Build assets locally
2. Push to GitHub
3. Wait for jsDelivr to update (usually < 1 minute)
4. Update Webflow custom code if file names or versions changed
5. Publish Webflow site
