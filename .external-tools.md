# External Tools Integration

This document tracks all external tools, APIs, and services integrated into the Astons Law Chambers project.

## Template for New Integrations

When adding a new external tool, use the following format:

```
## Tool Name
- **Purpose**: What the tool does
- **API Key Location**: Where the key is stored (env vars, secrets manager, etc.)
- **Usage Pattern**: Code example or integration method
- **Rate Limits**: Any constraints or quotas
- **Fallback Strategy**: What to do if the service fails
- **Documentation**: Link to official docs
```

## Security Guidelines

- Never commit API keys or secrets to the repository
- Use environment variables for local development
- Use GitHub Secrets for CI/CD pipelines
- Rotate keys regularly
- Implement proper error handling for all external API calls
